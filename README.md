# 🕌 QuranKu - Kloning Quranify Gratis

Aplikasi Al-Quran digital mirip Quranify dengan backend Express + database JSON.

## Fitur
- Home (Recently Played, Favourites, Playlists, Insights, Top Reciters)
- Reciters (daftar qari)
- Playlists (grid kartu)
- Settings (Premium, Redeem Code, dll)
- Search (cari qari/playlist)
- Mini player + Full player
- Dark mode ala Quranify

## Cara Menjalankan Lokal
```bash
npm install
npm start
